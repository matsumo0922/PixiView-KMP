## Requirements
### Requirement: 画面のエラー状態に変換される FANBOX API の失敗を種別ごとに分類する

アプリは、画面のエラー状態へ変換される FANBOX API の失敗を、認証切れ / 権限不足 / 未検出 / レート制限 / サーバ障害 / ネットワーク断 / スキーマ不一致 / その他 の種別へ分類しなければならない（MUST）。分類できない失敗はその他として扱う。

一覧の追加読み込み（ページング）の失敗はこの Requirement の対象外とする。

#### Scenario: 認証切れ

- **WHEN** FANBOX API が HTTP 401 を返す
- **THEN** アプリは失敗を認証切れとして分類する

#### Scenario: レート制限

- **WHEN** FANBOX API が HTTP 429 を返す
- **THEN** アプリは失敗をレート制限として分類する

#### Scenario: ネットワーク断

- **WHEN** 応答を受け取る前に通信が失敗する
- **THEN** アプリは失敗をネットワーク断として分類する

#### Scenario: サーバ障害

- **WHEN** FANBOX API が HTTP 5xx を返す
- **THEN** アプリは失敗をサーバ障害として分類する

#### Scenario: スキーマ不一致

- **WHEN** FANBOX の応答がアプリの期待する形式に一致しない
- **THEN** アプリは失敗をスキーマ不一致として分類する

#### Scenario: 分類できない HTTP ステータス

- **WHEN** FANBOX API が 400 など、いずれの種別にも当てはまらない HTTP ステータスを返す
- **THEN** アプリは失敗をその他として分類する

#### Scenario: FANBOX 由来でない失敗

- **WHEN** FANBOX API の呼び出しが FANBOX 由来でない例外で失敗する
- **THEN** アプリは失敗をその他として分類する

#### Scenario: 処理の中断

- **WHEN** 画面から離れるなどしてコルーチンが中断される
- **THEN** アプリは中断を失敗として分類せず、エラー表示も行わない

#### Scenario: ページングの失敗

- **WHEN** 一覧の追加読み込みが FANBOX API の失敗で終わる
- **THEN** 画面は従来どおりの読み込みエラー表示を行う

### Requirement: 分類に応じたエラー文言を表示する

エラー画面は、失敗の分類に応じた文言を表示しなければならない（MUST）。分類がその他の場合は呼び出し元が指定した文言を表示する。

#### Scenario: 認証切れの文言

- **WHEN** エラー画面が認証切れの失敗を表示する
- **THEN** 画面はセッションが切れたことを示す文言を表示する

#### Scenario: レート制限の文言

- **WHEN** エラー画面がレート制限の失敗を表示する
- **THEN** 画面はしばらく待つよう促す文言を表示する

#### Scenario: ネットワーク断の文言

- **WHEN** エラー画面がネットワーク断の失敗を表示する
- **THEN** 画面は接続の確認を促す文言を表示する
- **AND** 画面は再試行ボタンを表示する

#### Scenario: その他の失敗

- **WHEN** エラー画面がその他に分類された失敗を表示する
- **THEN** 画面は呼び出し元が指定した文言と再試行ボタンの文言を表示する

### Requirement: 分類を伴わないエラー表示も従来どおり成立する

FANBOX API 以外の理由で生じるエラー表示（課金情報の取得失敗など）は、分類を指定せずに従来の文言で表示できなければならない（MUST）。

#### Scenario: 分類を指定しないエラー表示

- **WHEN** 画面が分類を指定せずにエラー状態を生成する
- **THEN** 画面は指定された文言をそのまま表示する
- **AND** 分類はその他として扱われる

#### Scenario: 固有の再試行ボタン文言を持つ画面

- **WHEN** ファンカード画面が FANBOX 由来でない理由でエラー状態になる
- **THEN** 画面は従来どおり固有の文言と「戻る」ボタンを表示する
