## ADDED Requirements

### Requirement: 支援プラン一覧は部分的なスキーマ不一致で全体が失敗しない

支援プラン一覧の取得は、デコードできない項目を含む応答を受け取った場合、その項目を除いた残りのプランを返さなければならない（MUST）。呼び出し側は部分的な結果を通常の成功として扱う。

#### Scenario: 1 件のプランがデコードできない

- **WHEN** FANBOX が 3 件のプランを返し、そのうち 1 件が期待するスキーマに一致しない
- **THEN** 支援プラン一覧画面はデコードできた 2 件を表示する
- **AND** 画面はエラー表示に遷移しない

#### Scenario: すべてのプランがデコードできない

- **WHEN** FANBOX が返したすべてのプランが期待するスキーマに一致しない
- **THEN** 支援プラン一覧画面は空のリストとして表示される
- **AND** 画面はエラー表示に遷移しない

#### Scenario: 応答そのものが失敗する

- **WHEN** 支援プラン一覧の取得が HTTP エラーまたはネットワークエラーで失敗する
- **THEN** 支援プラン一覧画面はエラー表示に遷移する

### Requirement: スキーマ不一致の項目をスキップしてもユーザーには通知しない

リスト取得でスキーマ不一致の項目がスキップされた場合、画面は残りの項目を通常どおり表示し、スキップの発生を示す表示を行ってはならない（MUST NOT）。

#### Scenario: 部分表示時の画面

- **WHEN** リスト取得で 1 件以上の項目がスキーマ不一致によりスキップされる
- **THEN** 画面は残りの項目のみを通常のリストとして表示する
- **AND** 警告バナー、件数表示、その他スキップを示す UI 要素は表示されない
